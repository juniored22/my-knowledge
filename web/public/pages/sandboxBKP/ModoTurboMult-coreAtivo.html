🧠 O que é esse teste?

Este teste cria vários Web Workers (um por núcleo) que rodam loops pesados para simular o uso real da CPU em um cenário de processamento intenso.

A main thread monitora o tempo médio de resposta dos workers (lag) para detectar possíveis quedas de performance e throttling (limitação térmica).

Útil para entender como o navegador distribui carga entre núcleos lógicos em celulares ou desktops.
