🧠 O que é esse teste?

Este é um experimento de modo TURBO em aplicações web, feito para estressar o máximo da CPU de um dispositivo (principalmente celular) e monitorar a performance.

Um Web Worker roda um loop pesado de processamento para simular carga contínua na CPU. Enquanto isso, a thread principal mede o FPS e o tempo de resposta do worker para detectar possíveis sinais de throttling (redução de desempenho por superaquecimento).

O teste exibe também a quantidade de núcleos disponíveis e estima o uso de CPU com base no tempo de resposta do worker. Se o "lag" ficar alto, é provável que o sistema esteja limitando o processador.
